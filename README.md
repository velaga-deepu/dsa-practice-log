# DSA Practice Log

A running log of solved data structures and algorithms problems in Java, organized by topic, with notes on approach and complexity.

## Purpose
Building consistent DSA fluency by solving problems regularly and documenting *why* a solution works, not just the code itself — the way I'd need to explain it in an interview.

## Structure
Problems are grouped by topic (arrays, strings, recursion, etc.). Each file is self-contained and runnable, with a comment block at the top explaining the problem, approach, and time/space complexity.

## Problems Solved So Far
- **Two Sum** (arrays) — HashMap lookup, O(n)
- **Maximum Subarray** (arrays) — Kadane's Algorithm, O(n)

## Tech Stack
Java

## How to Run
Each file has a `main` method — open it in any Java IDE (or VS Code with the Java extension) and run directly.

## What I'm learning
Recognizing patterns across problems (e.g., when a HashMap beats brute force), and practicing writing complexity analysis clearly enough to explain out loud.
